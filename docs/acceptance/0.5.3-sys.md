# 0.5.3-sys 驗收清單（開發大哥＋策劃鎖定｜缺一退回）

產品：牧場手帳／farm-ledger　版本：`0.5.3-sys`

## 八項閘門（必須全部通過）

1. **熱區四態清晰**：idle／可點／按下／禁用  
   - 九個可見物件層（`hotspot_*.png`），唔係透明 hitbox。  
   - 撲滿熱區＝轉帳預填；禁用例：可用帳戶 < 2 時扑满 disabled（灰階＋唔可點）。  
   - 「今日有記」只做徽章／微光，**唔取代**可點／禁用語意。

2. **點擊回饋**：按下縮放（≈0.92）或琥珀高亮；≤200ms 有反應；`performHapticFeedback`／Compose haptic。

3. **浮標**：熱區上方短 label（分類名；撲滿顯示「轉帳」），唔擋點擊。點擊後另彈木名牌（分類＋最近一筆摘要）。

4. **頂欄獨立 UI**：`RanchTopBar` 木／奶油 chip — 日期／季節時段／連續記帳日／種子幣（＋可選 HK$ 月摘要小字）。**唔印死**喺牧場底圖。

5. **底欄四格獨立 chrome＋選中態**：牧場｜入帳｜帳簿｜日記（`RanchBottomBar` 木框＋印章紅底線）；中央＋預留。

6. **入帳夾板完整流**：開板→預填分類→金額（大數字鍵）→確認「記入牧場」→**收板回牧場**；目標 ≤3 tap ≤8s。

7. **帳簿紙感港幣流水**：可掃可搜、可進詳情編輯；空態紙頁插畫；商店買賣唔出現。

8. **日記紙感日結／習慣摘要**：今日有記／結清、連續日、漏記長草標記；**唔當第二套帳**。

## 一票否決

| 否決項 | 驗法 |
|--------|------|
| wallpaper（靜圖無回饋） | 牧場九物件可見＋按下有縮放／名牌 |
| 入帳唔經夾板 | Entry tab／熱區捷徑都用 `entry_clipboard` 流 |
| 商店寫真帳 | `buySeeds`／`sellHarvest`／`buyFeed` 只動種子幣＋背包；單元測試 `InventoryLogicTest` |
| 金幣當港幣 | 頂欄／帳簿分欄；種子幣標「≠HKD」 |

## 憲法（鐵則）加驗

- HKD ≠ 種子幣  
- 獎「有記／記全／對帳／儲蓄／預算內」，唔獎有錢；金額唔線性換幣  
- 漏記＝長草堆疊（1–min(N,3)），作物動物唔死、農場唔重置  
- 儲蓄熱區預填 **TRANSFER**，唔預填收入  
- 免費可好好記帳  
- **一日一結固定 seed**；改帳／同日重結 **唔重派**

## 試玩步驟（試GAME）

1. 開 App → 牧場：見 iso 底＋九個物件精靈＋浮標。  
2. 長按／點「飲食」：縮放＋名牌→入帳夾板已預填飲食／支出。  
3. 鍵入金額→記入牧場→自動回牧場；該熱區出現 ✓ 微光；草收起。  
4. 點扑满：類型＝轉帳；若只得 1 帳戶則扑满灰不可點。  
5. 頂欄 chip 顯示連續日／種子幣；底欄切換四 Tab 有選中紅線。  
6. 商店買種子：種子幣減、背包加；帳簿無新港幣筆。  
7. 漏記多日：草層可疊到 3。
