## 鐵則閘門

1. 第1日牧場橫屏只能見到 **3** 熱區（food／home／income）；多過三＝退回。
2. 未解鎖只係地圖捷徑唔出現；分類仍可經底欄入帳完整選。
3. 開局禁止灰未建桩、大木牌牆。
4. 頂欄唔得顯示連續。
5. 扑满解鎖後仍受帳戶閘（≥2 帳戶）——與可見性正交。
