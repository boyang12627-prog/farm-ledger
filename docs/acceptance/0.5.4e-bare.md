## 頂欄

| 項 | 要求 |
|----|------|
| 中牌文案 | `第 x 日`（ranch／game day） |
| 禁止 | 頂欄顯示「連續 N 日」（連續只放日記 Tab） |
| 種子袋 | 仍顯示 seedCoins 數字 |

## 開局／渲染

| 項 | 要求 |
|----|------|
| 底圖 | `spring_ranch_bare_day1` |
| Day1 visibleHotspots | **empty**（零門廊／灶／郵箱／灰桩／木牌） |
| 渲染閘 | `shop_day_reached AND owned`；否則完全隱藏 |
| 物件來源 | 種子幣商店「建造／購買」後先浮現；**唔寫港幣帳** |

## 商店

| 項 | 要求 |
|----|------|
| 開門 | `totalSettleDays ≥ 1` |
| 擁有持久化 | `PlayerProgress.ownedHotspotIds`（DataStore／game_prefs） |
| 入帳 | 底欄「入帳」**全分類**照常（未建唔鎖分類） |
