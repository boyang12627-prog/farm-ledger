# 0.5.4b-land FarmScreen UI tree（A2c_landscape_label_spec）

## Orientation
- `MainActivity` `android:screenOrientation="sensorLandscape"`
- Design base 1280×720 (16:9); `values-v28` cutout `shortEdges`
- Insets: Scaffold `WindowInsets.safeDrawing`; bottom bar `navigationBars ∪ displayCutout`

## Default path (`FarmScreen.kt`)
```
Box(fillMaxSize, SoftRanchSky + soft spring_ranch_base alpha)
  Column(fillMaxSize)
    RanchTopBar(floating chips: season/weather | streak | seeds | settings gear)
      — NO full-bleed solid bar; NO HKD on ranch HUD
    [optional clock-paused banner]
    RanchHotspotScene(weight 1, horizontal 16dp)
      — objects only idle; NO permanent floating_wood_sign
      — long-press ≥400ms → WhisperLabel (whisper_label.png, ≤4字, max 1 tip)
    [optional message]
```
Scaffold bottomBar = RanchBottomBar (~56dp landscape strip) + insets.
週回顧 → Diary Tab only.

## Label policy (spec §3)
| Mode | Behavior |
|------|----------|
| A default | No text labels |
| B long-press | whisper tip ≥400ms, release dismisses |
| C / a11y | `showHotspotLabels=true` |

`floating_wood_sign` → system toast / empty-state / settings only (WoodNameplate).

## Forbidden on default path
- 起床／物品欄／選擇作物／等待入晝／瞓覺
- 九熱區常駐中文木牌
- 牧場 HUD 真帳 HKD
- FarmScreen bottom「週回顧／設定」row
